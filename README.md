# Retail Sales & Customer Analytics

## Project Overview
This project uses MySQL to analyze retail sales, customer
purchasing behavior, product performance, payments, and returns.

## Database
Database: retail_analytics

Tables:
- customers
- products
- orders
- order_items
- payments
- returns

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- JOINs
- Subqueries and CTEs
- CASE statements
- Window functions
- Common business analysis queries

## Business Questions
The project explores customer spending, monthly sales,
top-selling products, product category revenue, payment
statuses, returns, and customer segmentation.

## Tools
- MySQL
- MySQL Workbench

## Dataset
This project uses sample data for practice and learning.
